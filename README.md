## 🚀 How to Enable GitHub Pages (Free Hosting)

1. Push or upload all files from this folder directly into your GitHub repository root.
2. In your repository on GitHub, go to **Settings** &rarr; **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `main` (or `master`)
   * **Folder**: `/ (root)`
4. Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/<your-repo-name>/`
